# Experimental Demonstrations

This folder contains video demonstrations of the complete execution pipeline of the Latent Objective Learning framework.

The videos provide experimental evidence of the implemented research pipeline, including:

- Human motion dataset preparation
- Dataset validation
- Foundation encoder training
- Latent representation evaluation


## Pipeline Overview


Human Motion Data
        ↓
Foundation Dataset Preparation
        ↓
Dataset Validation
        ↓
Multi-Branch Motion Foundation Encoder
        ↓
Latent Representation Evaluation
        ↓
Latent Objective Discovery
